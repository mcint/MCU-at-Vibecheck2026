Quick read (20 s)

What you're looking at: a real 2026 federal rule. Marketplace premium tax credits stop at 400% of the poverty line ($62,600). Maya earns exactly that; a $1 raise ends her $141/month credit — a cliff that costs $1,691/year.

What's proven: the rule is written as a 5-line Lean function. Lean proves current_has_cliff (∃ an income where $1 costs $141/mo) and, for a hypothetical taper repair, proposed_no_cliff: for every income, a $1 raise never raises the premium by more than $1/mo. No sorry, no native_decide; the #print axioms output is shown verbatim.

How to attack it: drag the MAGI slider or type any income (0–200,000). The tiles re-run through the compiled Lean binary when the local server is up (badge says "native Lean"); otherwise a JS mirror of the same definitions. Try to find an income where the green rule jumps by more than $1.

    /-- Federal PTC in the modeled 300–400% FPL band. Eligibility above 400% is zero. -/
def currentCredit (income : Nat) : Nat :=
  if income < lowerModeledIncome then 0
  else if income ≤ cutoffIncome then benchmarkPremium - monthlyContribution income
  else 0
-- Hypothetical: keep the cutoff credit, taper it to zero over the next half-FPL ($7,825).
def proposedCredit (income : Nat) : Nat :=
  if income < lowerModeledIncome then 0
  else if income ≤ cutoffIncome then currentCredit income
  else
    let initial := currentCredit cutoffIncome
    let width := povertyGuideline / 2
    let reduction := min initial (((income - cutoffIncome) * initial) / width)
    initial - reduction

    What is NOT proven

    Lean proves the encoded arithmetic (constants: FPL $15,650, 9.96% band rate, $661 KFF Texas benchmark, Form 8962 rounding), not Maya's personal eligibility, other income taxes, local plan prices, or that the taper is good policy. The cliff is in IRS rules; this demo did not discover it. The taper is hypothetical. proposed_no_cliff bounds the monthly premium step at $1 per $1 of annual income — it does not say net annual income is monotone (a $1/mo step is $12/yr).
